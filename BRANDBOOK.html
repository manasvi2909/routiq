UX principles

Experience rules

Ritual over task

Every flow should feel intentional, not like generic item management.

Progress must be visible

Users should always understand what changed, what advanced, and what unlocks next.

Editing must be safe

Goals, rewards, windows, reminders, and plant choice must remain adjustable midstream.

Dark mode is first-class

Contrast and atmospheric richness are required, not optional.

Component language

UI behavior

  • Use tinted glass cards, not flat white boxes.
  • Primary actions use green gradients and restrained depth.
  • Navigation remains premium, rounded, and spacious.
  • Modals must scroll when content grows.
  • Circular icon buttons must visually center icons.
  • Plants are identity-bearing UI elements, not filler decoration.
Motion language

Alive, not busy

  • Ambient drift for atmosphere layers
  • Gentle pulse for live or active signals
  • Soft hover lift on premium actions
  • Celebration only for meaningful progress moments
  • Standard interactions at roughly 180ms to 220ms
Data visualization

Charts as composition

  • Never drop in generic default chart styling.
  • Use brand palette mapping from token values.
  • Keep chart labels legible in both themes.
  • Use data views to tell a mood-and-rhythm story, not only counts.
  • Reports should feel like an archive, not business intelligence software.

Next horizon

How the system can mature from here.

The current identity is strong enough to scale. The next step is formalization: assets, motion standards, illustration consistency, and deeper cross-platform handoff.

Closing roadmap

Brand evolution plan

01

Formalize the identity

Create SVG logo masters, app icon sets, monochrome variants, and a final export package.

02

Tokenize everything

Move remaining visual rules into clean design tokens across code and Figma for easier scaling.

03

Expand the product language

Build a deeper botanical illustration library, richer chart patterns, and milestone ceremony variants.

04

Prepare external touchpoints

Extend the system into pitch decks, social assets, onboarding, store graphics, and a public-facing site kit.
